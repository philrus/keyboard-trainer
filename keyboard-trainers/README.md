# Клавиатурный тренажер
Тренажер для тренировки печати текста на английском языке. Он представляет из себя окошко со строкой ввода (куда пользователь должен будет ввести предложенную строку, принимаются только правильные символы), вывода, нарисованной клавиатуры, а также количеством ошибок и скоростью печати посчитанных для последней введеной строки. На рисованной клавиатуре желтым цветом подсвечивается только что нажатая клавиша, а красным та клавиша, на которую пользователю надо нажать. В файле tasks.txt находится файл с заданиями, программа считывает строки и в случайном порядке предлагает пользователю. Время для статистики считается от первого правильно введеного символа в строке, до последнего символа введеного в строке. В файле statistics.txt находится статистика за все время: строка 1. Количество ошибок. 2. Время работы в секундах. 3. Количество введеных строк. 4. Среднее количество ошибок за раз. Как только пользователь правильно введет строку, сразу же появится следующая.
